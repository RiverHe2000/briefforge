# BriefForge 演示步骤

## 三分钟主线

1. 打开工作台，选择内置案例。指出“虚构测试资料”和“固定响应回放”标识。
2. 在资料页查看三家竞品的30份文件，打开旧版SSO说明及新版企业版权益。
3. 审阅研究大纲，启动回放。协作页显示专业任务、独立核查、补查原因和结果。
4. 打开报告，从竞品SSO结论跳到原文，解释“仅企业版支持”与“不支持”的区别。
5. 下载Word和PPT，展示相同报告版本、相同计费条件及来源编号。
6. 将一份价格表替换为新版后重新研究，展示受影响结论更新和历史报告仍然存在。

免费回放便于稳定演示系统行为。面试中同时展示真实模型结果及失败案例，不能把回放界面描述为真实推理。

## 真实运行演示

确认服务端密钥有效后，复制一个合成案例并选择真实模型。界面显示实际模型请求数、确认费用和待确认费用。公开资料工作区可以输入真实产品名字并联网研究，网页来源会保留URL及获取时间。

## 可讨论的工程问题

- 为什么把事实与报告叙事分开，Word和PPT如何保持一致？
- 如何防止旧任务覆盖恢复后的新结果？
- 为什么“引用能找到”仍不等于“结论正确”？
- 多Agent的额外调用是否带来足够收益？失败时怎样解释成本？
- 哪些更新只影响一个结论，哪些变化需要重新调查整个问题？
