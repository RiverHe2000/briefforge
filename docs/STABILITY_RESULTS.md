# 稳定输出与可见协作

2026-10-03。本次改进沿用原 PostgreSQL 费用账本，没有重置预算或覆盖历史失败。

## 实现变化

- 报告新增“协作带来的变化”：前后结论、原文、补查、实际任务时间线和费用。资料更新直接展示相邻冻结报告的版本差异，不将版本变化伪装为模型纠错。
- “沿用结论”按正文、状态、值、条件、引用和计算字段完全一致统计；计划复用另存，缺少记录时显示未知。
- 新研究默认采用实测 Gemini 低价配置；Qwen 保留为显式实验选项。旧运行沿用原配置，没有自动换模型。
- 从所引原文整理完整价格事实，统一金额、币种、周期、税费和企业询价条件。三种架构共享此规则，其收益不能专归于多 Agent。
- 按实际任务约束主体和维度，避免模型改写“行业”名称后丢失有效结果。格式修复仍只有一次，所有尝试计费。
- 明确同主体、同字段、被替代日期的后续资料可以解释历史变化；同日、无日期、无关字段或其他现行矛盾仍保留未知。
- 编辑员的摘要引用确定性去重、选择最多八项，正文保留全部结论，不因九个摘要引用阻断报告。
- 修复 PPT 价格页重叠，完整价格文字保持不变。渲染器版本进入导出缓存键，保留旧文件，修复版可重新生成。

重复冲突诊断中，多 Agent 和固定流水线保留了双方引文，单 Agent 两次仅引一方。终稿都没有对无法解决的冲突强行选边。核查与补查的过程可追踪，但撤回为未知不等于找到了答案。

## 完整对照与局限

v5 实现冻结后运行原 8 个案例 × 3 架构，共 24 次真实对照，全部完成。相同六项事实检查器离线重评 v4/v5，历史数据保留。

| 架构 | v4 事实检查 | v5 事实检查 | v5 请求 | v5 确认费用 |
| --- | ---: | ---: | ---: | ---: |
| 单 Agent | 97.92% | 93.75% | 8 | US$0.023105 |
| 固定流水线 | 58.33% | 75.00% | 57 | US$0.053137 |
| 动态多 Agent | 64.58% | 83.33% | 85 | US$0.071643 |

这是三个价格和三个 SSO 义务的有限模式检查，**不是全文准确率**。独立审阅发现：72 条价格的金额、单位、税费和企业询价条件均正确。23 项自动未通过中，16 项是中文日期与 ISO 写法的匹配误报，3 项是冲突结论安全但细节不全，4 项是有答案却撤回。评分规则没有为改善成绩而修改。[配对统计](../artifacts/semantic-metrics-v2/v5/paired-v4-v5.json) · [语义审阅](../artifacts/evaluation-live-gemini-v5/semantic-review.json)

相同八例中，动态多 Agent 的请求从 187 次降到 85 次，费用从 US$0.100912 降到 US$0.071643，约降低 29%。该版本同时修改上下文、公共事实校验和温度，不能归因于单一改动。单 Agent 仍最便宜，整体检查分也更高。

随后预先安排两类质量场景各重复两次，加三个架构的更新前/局部更新/全量重跑，共 21 次。全部完成，费用 US$0.133208，但发现新版明确替代仍被误判为冲突。[这轮失败质量样本完整保留](../artifacts/reliability-live-v1/semantic-review.json)，任务完成不等于答案正确。

最后针对任务标识、明确替代和摘要选择进行修复。三次协议试跑原有一次编辑失败，其恢复另记；九次更新验证均完成，六项检查均通过，独立审阅确认多 Agent 更新目标正确且 18 条非目标结论不变。它们是已知问题的回归验证，不是未见测试集；没有声称最终代码重跑了原来整组 24 例。

机会建议仍是待验证假设。v6 草稿存在无依据的“安全合规需求日益增长”前提，已在[审阅](../artifacts/protocol-v6/review.json)中指出。本轮未重测真实公开网页研究，历史联网质量限制继续适用。
