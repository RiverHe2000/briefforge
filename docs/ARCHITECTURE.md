# BriefForge 架构

## 数据与执行边界

浏览器通过FastAPI管理研究需求、资料和报告。API创建持久化作业后立即返回。独立Worker领取作业，以LangGraph执行发现、规划、研究、核查、补查和编辑阶段。

PostgreSQL保存业务记录、事件、费用预留和Worker租约，LangGraph使用PostgreSQL检查点。SQLite兼容模式为本地启动和单元测试提供较轻的入口，检查点在独立文件中。报告不是对当前数据库内容的动态视图，而是包含完整来源与结论的不可变快照。

## 多 Agent 的实际分工

协调员安排任务；竞品研究员按目标分工，行业和商业分析拥有不同的问题范围；独立核查员判断原文是否支持结论并提出补查请求。模型每次只收到与任务相关的材料，不共享无限增长的聊天历史。

专业Agent拥有只读资料工具：检索冻结资料、读取选定来源、提交带原文引用的结论。工具参数经过验证，不能执行代码或访问其他工作区。公开网页中的指令也只属于待研究文本。

研究输出及核查问题按本任务的主体、维度和有效组合绑定模式。未知名称、跨公司条目或缺失任务槽位触发现有的一次格式修复；不会用模糊名称匹配把断言改挂到另一家公司。行业补查仍由行业角色读取行业资料。

传给模型的参数模式使用完整内联对象，避免供应商转换器遗漏嵌套定义。模型提交不符合模式的参数时，工具不会执行；系统可付费修复一次，仍失败则保留原始响应并暂停任务。修复与网络重试都占用请求次数及预算。

Gemini 的服务端模式保留对象结构、必填项和枚举，省略容易造成解码状态膨胀的长度与数值约束。完整约束仍写入提示，并由本地 Pydantic 在工具执行前强制校验；读取来源数量、文本长度和费用上限保持不变。

每组真实对照评测固定同一型号和线路，以免把模型差异误认为协作收益。单Agent基线使用一次合并研究；固定流水线使用顺序专业分工和核查；动态系统支持并发与核查后的补充调查。单Agent基线的工具使用范围与动态系统仍有编排差异，因此评测解释需保留这一限制。

运行创建时将模型配置冻结到 `Run.model_profile`；恢复沿用该选择。旧运行没有此字段时仍按原来的 Qwen 配置解释。系统不因限流或输出错误自动换模型或线路，另一配置需要创建新运行，其评测结果单独存放。

| 配置 | 固定模型 | 固定线路 | 用途 |
| --- | --- | --- | --- |
| `gemini-budget` | `google/gemini-2.5-flash-lite` | `google-ai-studio` | 新运行默认的已实测配置，不施加 FP8 条件 |
| `qwen-default` | `qwen/qwen3-235b-a22b-2507` | `gmicloud/fp8` | 保留供显式选择的实验配置，限定 FP8；旧运行继续沿用 |

两者每次启动都检查工具、结构化输出与输出长度控制能力，以及每百万输入/输出 token 不高于 US$0.10/0.40 的价格上限。请求只允许所选线路，禁用供应商自动后备。响应凭据和结算记录保存配置、型号、线路与实际用量，目录能力检查本身不代表完成了真实运行验证。

新请求使用温度 0 减少措辞变化，但这不保证供应商结果完全确定。默认配置变更仅影响新运行；缺少配置字段的历史记录仍按原来的 Qwen 配置解释。响应包或用量字段异常也先记账，保留未知费用并报告可恢复错误，不因诊断代码异常跳过结算。

## 证据、版本与修改

每份资料有逻辑身份、内容哈希、版本和时间。替换资料时保留旧版，标记引用旧来源的结论需要更新。一次运行冻结资料ID，运行期间资料变化不会偷偷修改已有证据。

每条结论包括主体、维度、状态、引用和适用条件。逐字定位校验只证明引用存在；语义支持由独立核查处理，评测参考不使用系统自己的核查结果。价格计算与图表保留币种、单位和计费条件，缺少统一口径时不绘制误导性价格比较。

研究与核查共用有字符偏移的原文窗口，每个来源最多选取12,000字；已有引用优先，其次按任务维度的中英文关键词选择片段，并保留页首。长页尾部的套餐条款因此可以进入上下文，未纳入的引用数量会明确标记。URL、抓取时间、发布日期分别保留；抓取时间不能替代发布日期。窗口选取不能恢复HTML扁平化过程中丢失的表格列关系，无法确定套餐关联时仍须保留未知。

日期校验覆盖结论、值和适用条件，将完整中英文数字日期与所引原文及来源发布日期比较；不支持的日期会使断言撤回，并形成有界补查。核查员的转述也接受同样的证据约束。只有旧资料明确标注已过时、时间严格先于后续资料、同一主体同一字段的现行原文一致时，系统才将历史差异归为版本变化；同日冲突、无日期资料和普通旧页不会自动按新旧排序消除。该规则适用于有明确字段的材料，不代替一般语义判断。未解决事实被其他章节重复引用时，其不确定性会同步保留。用户指定的时间范围及运行创建日期提供给所有模型角色。

价格周期校验分别扫描结论、值和条件，只在同一明确币种、同一金额的月/年报价单位与逐字引用直接矛盾时撤回断言并补查。“按年付款”不被当作“每年报价”；不同金额的年总额、不同币种和无明确单位的表述不据此推算或判错。该规则不代替币种、套餐归属和计算公式的独立核查。

报告编辑选择有依据的结论、组织章节，并把差异化机会标为待验证假设。Word与PPT读取同一个报告快照，使用确定性导出模板。旧报告导出保留原有版本，不将当前资料混入历史文件。

明确替代旧条款也能解释时间变化：替代声明必须来自同主体，指明同一事实字段与旧资料的准确日期，且自身发布日期及生效日期更晚。仅较新、同日、无日期、跨发布者或其他现行冲突都不能自动胜出。只引用已替代旧条款仍会触发补查。模型编辑最多返回四十个引用键，再确定性筛出最多八个有效、不重复的摘要引用；正文保留全部结论，发生缩减时记录事件。

稳定性改进中，模型先为各角色输出结构化研究结果，按维度挑选的上下文覆盖相关 FAQ；补查保留有界资料工具。对模型选定来源中可直接定位、无歧义的完整定价段落，系统编译原文金额/币种/周期并统一渲染结论、值和条件。不同来源存在未解决矛盾时不能据此任选一方；扁平化表格关联不清时不推断套餐。三种架构使用相同事实检查规则，不能把公共校验器的收益归因于多 Agent。

决策事件记录修改前后字段、原因、来源、实际任务 ID 和轮次。`GET /api/runs/{id}/collaboration` 只读聚合这些事件以及开始/结束时间，输出结论变更、补查、复用和并行重叠。旧运行缺失的记录显示为空，恢复后没有结束时间的旧尝试标为中断。重叠时长仅是观测并发，不是相对单 Agent 的速度提升；同一结论多次修改按结论去重，且显示最终状态，避免把撤回也算成正确答案。

局部更新另外比较相邻冻结报告，生成明确标为 `report_revision` 的只读版本差异，事件 ID 为 null，不编造任务责任人。`planned_reused_claims` 是输入复用计划；`reused_claims` 仅计正文、状态、值、条件、证据和计算字段完全不变的结论，无法比较时为 null。重查数量是计划范围，与实际任务数分别展示。

## 恢复与并发

作业领取、预算预留和业务写入使用短事务。PostgreSQL通过账本行锁串行化关键事务，SQLite通过BEGIN IMMEDIATE实现同等小规模约束。锁内不执行网络请求或模型调用。此设计适合单用户工作台，吞吐量扩展时应拆分锁粒度。

Worker有带期限的租约和唯一令牌，定期续租；过期任务可以被其他Worker接管。每次提交校验租约，旧进程不能覆盖新结果。任务输出和图检查点双重保存，让并行批次中成功的工作能够复用。导出以报告内容哈希与格式去重。

导出去重键同时包含渲染器版本：修复版式后可以为同一冻结报告创建新文件，原有作业及下载仍保留；相同渲染版本的重复请求继续幂等。

外部LLM请求不提供事务性的exactly-once保证。进程在模型已计费、响应尚未保存时退出，仍可能产生未知费用；本系统保留预留和失败记录，不宣称收费调用绝不会重复。

## 费用与外部来源

所有HTTP模型尝试先预留保守成本，项目、类别和运行预算在同一个事务中检查。成功返回费用后结算，未知费用继续占用预算。发生费用偏差仍如实记录实际值，并停止后续超预算调用。

搜索适配器使用 `openrouter:web_search` Beta 服务端工具，固定 Parallel `basic`；每次请求 `max_uses=1`、顶层 `max_tool_calls=1`，最多三个结果。模型可以决定不调用搜索；每次尝试仍计入本次运行最多六次的保守限制。只使用服务返回的 URL 引用发现页面，实际获取正文之后才建立可引用来源。配置对应 [OpenRouter 搜索工具文档](https://openrouter.ai/docs/guides/features/server-tools/web-search)，需与真实试跑一起验证 Beta 接口兼容性。

网页获取只支持公共HTTP/HTTPS，解析并校验全部DNS地址后连接校验过的IP，HTTPS使用原域名校验TLS。每次重定向重新检查，禁止回环、局域网、云元数据地址及非标准端口。正文大小和重定向次数受限。

应用默认仅本机单用户。未来若部署给多人，必须增加认证、工作区权限、独立用户预算与更严格的数据保留策略，当前不声称具备这些能力。

## 测试资料与评价

演示资料与冻结答案由不同模块持有。答案文件只被评测模块读取。四个开发场景和八个测试场景包含价格口径、SSO套餐、版本冲突、缺失信息与注入文本。明确显示合成属性，真实公网研究与合成案例不混用。

回放是为了复现机制的确定性实现，不能证明LLM效果。真实评测记录失败、耗时、费用、引用与独立参考检查，通过相同资料和费用上限比较三种架构。小样本结果不用于声称普遍优越性或真人效率提升。
